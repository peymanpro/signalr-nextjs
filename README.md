# SignalR Next.js Chat Client

A beautiful, modern real-time chat client built with Next.js and SignalR. Connects to any SignalR backend (like the ASP.NET Core SignalR chatroom) and provides a complete chat experience with online users, typing indicators, and system notifications.

## Features

- ✅ Real-time messaging with timestamps
- ✅ Online users list with live updates
- ✅ Join and leave notifications
- ✅ Typing indicators
- ✅ Personal welcome message
- ✅ Connection status indicator
- ✅ Responsive design (works on mobile/desktop)
- ✅ Pure JavaScript (no TypeScript, no Tailwind)
- ✅ Simple CSS with animations


| Next.js 14 | React framework |
| SignalR | Real-time communication |
| CSS-in-JS | Styling with animations |


- Node.js 18+ or 20+
- A running SignalR backend (e.g., [signalr-aspnetcore-public-chatroom](https://github.com/peymanpro/signalr-aspnetcore-public-chatroom))

 Run the development server:npm run dev
